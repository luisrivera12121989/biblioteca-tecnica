PWA Biblioteca Técnica CAEX 794 AC y 798 AC

El HTML original superaba el límite de 25 MB por archivo de GitHub. Se optimizó separando las imágenes incrustadas en 542 archivos dentro de assets/; el contenido y las ilustraciones se conservan.

PUBLICAR:
1. Descomprime este ZIP.
2. Usa GitHub Desktop para clonar el repositorio biblioteca-tecnica.
3. Copia todos los archivos y carpetas de este paquete dentro de la carpeta local del repositorio (incluyendo assets, icons).
4. En GitHub Desktop, confirma los cambios y pulsa Push origin.
5. En GitHub, Settings > Pages: Deploy from a branch; main; /(root).
6. Espera a que Actions muestre la publicación completada.

No subas solamente index.html: la carpeta assets es necesaria para mostrar ilustraciones.
